# なつほのAIホラー 公式ポータルサイト（公開用パッケージ）

## 概要
「なつほのAIホラー」のYouTube、TikTok、X、ニコニコ動画を束ねる公式ポータルサイト（index.html）の完全デプロイパッケージです。
デザインは本格ホラー70% × コメディ30%の黄金比で設計されています。

## 特徴
1. **完全無料運用（サーバー代0円）：**
   GitHub Pages（またはCloudflare Pages）を利用することで、月額費用・保守管理コストが一切かかりません。
2. **専属電脳技師「九十九」による品質保証：**
   JavaScriptの厳格な構文検証（バグ調伏）およびGoogleドライブ原本管理台帳との三位一体同期により、安定した表示と高速ロードを維持します。

## デプロイ手順
1. 本zipを解凍した内容（`index.html`、`favicon.ico`、`assets/` フォルダ）をGitHubリポジトリ（`natsuhonoai.github.io`）のルートへアップロード（コミット）します。
2. リポジトリの Settings > Pages にて Branch: `main` / `root` が選択されていることを確認します。
3. 数十秒後に `https://natsuhonoai.github.io/` にて最新版が公開されます。
