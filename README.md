# なつほのAIホラー 公式ポータルサイト（公開用パッケージ v2.0）

## 概要
「なつほのAIホラー」のYouTube、TikTok、X、ニコニコ動画を束ねる公式ポータルサイトの完全デプロイパッケージです。
本格ホラー70% × コメディ30%の黄金比で設計され、トップページと専用全作品アーカイブページの二層構成に進化しました。

## v2.0 の主要機能・特徴
1. **トップページ（index.html）：最新6作品ピックアップ**
   - トップページの軽快さと視線誘導を最適化するため、最新作を新しい順に6作品のみ表示。
   - セクション下部に「全作品アーカイブを見る（全32作品・怪異年表） →」へのシネマティック誘導バナーを配置。
2. **全作品アーカイブ専用ページ（works.html）新設：**
   - 全32作品を完全網羅。
   - カテゴリー絞り込み（すべて／長尺本編／ショート日常／おでかけ番外編）。
   - リアルタイム検索（作品名・怪異名・タグによるインクリメンタルサーチ）および並び替え（新しい順／古い順）。
   - 各動画の解説モーダル＆配信プラットフォーム視聴ボタン（YouTube、ニコニコ、TikTok、X）。
3. **Googleスプレッドシート自動連動（ダッシュボード直結）：**
   - 参謀が管理する『【なつほのAIホラー】全作品管理ダッシュボード』とポータルサイト（index.html & works.html）をGoogle Visualization API経由で直結。
   - シートに新作を行追加するだけで、GitHubへの再コミット不要でトップの最新作が自動更新され、全作品アーカイブにも即座に蓄積されます。
4. **トマトの神託・Googleスプレッドシート連動（案A）：**
   - 座長専用スプレッドシート（『【公式ポータル】トマトの神託管理台帳』）とのリアルタイム同期。
5. **三重防壁（セーフガード）設計：**
   - 全32作品および28パターンの神託データをHTML内部および静的JSONに内蔵しているため、通信障害やオフライン時でもサイトの表示崩れや遅延は一切発生しません。

## デプロイ手順
1. 本zipを解凍した内容一式（`index.html`、`works.html`、`favicon.ico`、`assets/` フォルダ）をGitHubリポジトリ（`natsuhonoai.github.io`）のルートへアップロード（コミット）します。
2. リポジトリの Settings > Pages にて Branch: `main` / `root` が選択されていることを確認します。
3. 数十秒後に `https://natsuhonoai.github.io/`（トップ）および `https://natsuhonoai.github.io/works.html`（全作品アーカイブ）にて最新版が公開されます。

## Googleスプレッドシートの公開共有設定
スプレッドシートと本番サイトをリアルタイム自動同期させるため、以下の2つのシートの共有設定を「リンクを知っている全員（閲覧者）」に設定してください：
- 『【なつほのAIホラー】全作品管理ダッシュボード』
- 『【公式ポータル】トマトの神託管理台帳』
